# 数据说明

- data/seed/biographies：可运行样例人物传记，保留原文来源与页码字段。
- data/seed/kg：样例人物和关系。
- data/seed/qa：自动生成的检索/选择题辅助样本。
- data/full/kg：全量结构化人物与关系数据。
- data/full/biographies：与本地完整版一致的 326 份传记文件，默认分块后为 9,921 个文本块，包含 265 个不同传记姓名。
- data/full/manifest.json：全部数据文件的 SHA-256、人物覆盖和图谱与传记姓名的差异名单。
- data/full/qa：全量弱标注评测辅助样本。
- data/demo_upload：用于验证摄取流程的示例资料。

完整传记原文已随仓库提供；个人上传资料、向量索引、模型权重、密钥和个人会话不发布。默认 MATHKB_DATA_DIR 指向 data/full，MATHKB_BIOGRAPHIES_DIR 留空即可加载其中的 biographies。运行 python scripts/verify_corpus.py 核验全部文件；--compare-dir 可与本地来源目录逐文件核对。

图谱共有 335 位人物和 355 条关系，图谱姓名与传记姓名存在别名及收录范围差异。326 是文件数，不能当作 326 位不同人物；图谱姓名缺少同名传记也不能单凭此认定现实中无此人物资料。系统回答范围取决于实际导入的证据。

来源文本的权利归原作者或权利人，仓库不授予原始资料的额外许可。人物级标注不能替代段落相关性标注和人工答案核验；图谱未记录某条关系不表示现实中不存在。
