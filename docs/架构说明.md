# 架构与数据流

接口层负责校验、应用令牌和 SSE；业务层负责会话、引用和摄取任务；Agent 层通过 LangGraph 实现 ReAct 循环；检索层组织 BGE、BM25、图谱和证据；存储层使用 SQLAlchemy 与 pgvector。

模型动作采用 JSON Action/Observation 协议，工具全部只读。默认最多 4 次工具尝试，非法动作和重复调用消耗预算。工具结果有大小上限，最终证据去重并编号。公开的工具名、参数、命中数和状态可保存到会话；不请求或保存模型内部思维链。

图谱从人物、领域与关系表构建 NetworkX 有向图。teacher 表示学生→老师，查询入边不能倒读。连接路径采用无向图，只证明连通，不证明师承方向。领域和籍贯匹配目前使用字符串规则。

worker 摄取提交后递增数据库索引版本，API 在请求快照中感知并刷新；Redis 缓存键包含配置与索引签名，数据更新后不复用旧结果。缓存仅存检索结果，不缓存最终答案。

上传解析与引用编号检查不等于关系抽取或事实核验。新上传文档更新文本索引，不会自动增加图谱师承边。
