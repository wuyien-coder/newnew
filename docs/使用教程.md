## 1. 启动本地版本

安装 Python 3.11+ 和 Node.js 22+，获取仓库后，在项目根目录的 PowerShell 执行：

```powershell
git clone https://github.com/wuyien-coder/newnew.git
cd newnew
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev,prod]"
Copy-Item .env.example .env
cd frontend
npm ci
npm run build
cd ..
.\.venv\Scripts\python.exe scripts/run_api.py
```

等待终端提示应用就绪，再打开 http://127.0.0.1:8010/web/ 。默认导入随仓库提供的全部传记，首次建立索引需要等待。Docker 完整版使用 http://127.0.0.1:8080/web/ ，完整部署命令见 [README](../README.md)。

## 2. 连接设置

左下角选择“连接设置”。默认本地离线配置不启用访问令牌，输入可留空；如果服务启用了认证，填写该服务的 `MATHKB_SERVER__API_TOKEN`，点击“保存并连接”。令牌仅保存在当前浏览器会话中。

网页的访问令牌用于访问应用，模型 API 密钥用于服务端调用模型，两者不同。不要把模型密钥填进网页的访问令牌框。

## 3. 提问与参考依据

在“知识问答”点击示例，或输入完整问题：

- 华罗庚在数论方面有哪些贡献？
- 苏步青师从谁？
- 研究微分几何的有哪些人？

Enter 发送，Shift + Enter 换行。生成时可停止；中断回答可能不完整。点击回答下方的参考依据入口，核对右侧人物、原文摘录、来源和引用编号。原文与图谱证据分别显示；检索参考强度不代表事实正确率。

默认 `stub` 模式只做离线资料摘录，不调用收费模型，不代表真实大模型回答。资料未记载的问题需要继续查证。

## 4. 人物关系与多轮会话

开启输入区的“图谱增强”，提问“华罗庚与熊庆来有什么关系？”或“苏步青师从谁？”。真实 ReAct 模式会依据问题选择检索工具；右侧可查看实际工具调用、参数和结果。当前界面通过问答查询人物关系，不提供独立的交互式图谱浏览页。

继续提问“请补充这段关系的原文依据”，建议明确人物姓名。左侧历史会话可恢复已保存的问答及引用；切换研究主题时点击“新建对话”。离线模式的追问能力有限，模型驱动的多轮问答需要接入真实模型。

## 5. 上传补充资料

打开“知识库”，点击“上传文档”或“选择文件”。支持 `.txt`、`.md`、含可提取文字的 `.pdf`，单文件最多 20MB；扫描 PDF 应先转成文字。

在“摄取任务”中等待任务从等待/处理中变成“已完成”，再在问答中检索新资料。失败任务可点击“重试”；刷新列表可核对入库状态。删除文档会把它移出知识库，请先核对。

## 6. 接入真实模型

在本机 `.env` 填入兼容 API 的实际配置，并重启后端：

```dotenv
MATHKB_LLM__PROVIDER=openai
MATHKB_LLM__BASE_URL=<服务商兼容 API 地址>
MATHKB_LLM__MODEL=<模型名>
MATHKB_LLM__API_KEY=<仅在本机填写>
```

`openai` 表示兼容接口提供方配置，不限定为某一家模型。使用符合服务商要求的地址、模型名和密钥，核对页面右上角模式。真实模型调用可能产生服务商费用；不要把 `.env` 和真实密钥提交到仓库。完整 BGE、PostgreSQL/pgvector、Redis、Celery 配置见 [部署说明](部署说明.md) 和 README。

## 7. 常见问题

| 情况 | 检查方法 |
| --- | --- |
| 网页打不开 | 确认后端仍运行；检查启动日志、实际端口和 `/web/` 路径。 |
| 身份验证失败 | 核对连接设置中的应用访问令牌与服务器配置一致。 |
| 只有资料摘录 | 检查是否仍为 `stub`；真实模型配置后需重启后端。 |
| 上传后搜不到 | 确认摄取任务已完成，刷新列表；失败时查看原因后重试。 |
| 答案没有所需信息 | 补充人物名或改写问题，核对资料覆盖；不要把空查询当作支持证据。 |
